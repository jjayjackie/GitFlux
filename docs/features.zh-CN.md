# 面板功能

[English](features.md)

高级 Git 是一个面板，可作为工作区标签页打开，也可在资源管理器中使用。它分三栏：左侧是导航，中间是所选仓库的更改与提交图，右侧是所选内容的详情。各栏及中间的两个窗格都可以拖动调整大小；按 Alt+E 可隐藏导航。当面板比桌面侧边栏还窄时，一次只显示一个窗格，以标签（更改、提交图、分支）切换，详情则覆盖在上方显示。

每个操作都有带提示的按钮，也出现在行的右键菜单中（手机上为长按）；常用操作还有键盘快捷键（在面板中按 `?` 查看列表）。所有列表都是虚拟化的：即使仓库有十万个提交或一万个已更改文件，面板依然流畅；任何被截断的内容都会明确提示。

面板在哪些方面遵循 VS Code、在哪些方面有所不同以及原因，见 [design.md](design.md)。

## 仓库

导航列出工作区文件夹中的仓库：文件夹本身的仓库、子文件夹中的仓库、它们的子模块以及关联的工作树，嵌套显示在所属仓库之下。扫描哪些文件夹遵循该文件夹 `.vscode/settings.json` 中的 VS Code 设置（`git.autoRepositoryDetection`、`git.repositoryScanMaxDepth`、`git.repositoryScanIgnoredFolders`、`git.scanRepositories`、`git.ignoredRepositories`、`git.openRepositoryInParentFolders`）。每一行显示分支、待拉取和待推送的提交数，并标记已更改、已暂存、有冲突的文件以及正在进行的合并或变基。选中某个仓库后，面板其余部分即显示该仓库。Git 无法读取的仓库也会列出，并说明原因。仓库列表每十秒重新读取一次。

## 更改

- **文件。** 冲突、已暂存和未暂存的文件，各自以文件夹树（或平铺列表）显示，并带有文件状态和 `+新增 −删除` 行数。可以对单个文件、文件夹或整组执行暂存、取消暂存和放弃更改；可以打开差异、文件本身、文件历史或 blame；可以把文件加入 `.gitignore`。筛选框可缩小列表范围。
- **放弃更改**前会先询问并列出文件（除非在设置中关闭了这项确认）。未跟踪的文件会移到废纸篓；无法移入时会再次询问是否永久删除。已跟踪的更改会先记录到安全快照中。
- **提交。** 消息框以 Git 的 `commit.template`，或合并/重放中提交的消息作为初始内容，并按仓库保留草稿。主题行超过 50 和 72 个字符时会提示。可以提交、只提交已暂存内容、全部提交（先暂存所有内容）、修订上一次提交、添加 Sign-off、提交并推送、提交并同步。修订已推送的提交前会先询问，因为之后需要强制推送。Git 钩子总会执行。⌘Enter / Ctrl+Enter 提交。
- **进行中的操作。** 在合并、变基、拣选或还原过程中，横幅会说明当前进度（例如第 3/7 步、正在应用的提交），并提供“继续”“跳过”“中止”。仍有冲突文件时无法继续；中止前会说明将丢弃的内容，并先创建快照。
- **超大的工作树。** 与 VS Code 一样，状态最多读取 10 000 个文件；超出时会给出提示，并提供把导致问题的文件夹（如 `node_modules`）加入 `.gitignore` 的选项。

## 工具栏

显示仓库及其分支（点击分支可切换分支）、待拉取和待推送的提交数，以及“获取”“拉取”（合并、变基或仅快进）、“推送”（没有上游的分支显示为“发布”，可选择远程）和“同步”按钮。强制推送位于“推送”的菜单中：始终使用 lease，仅在主机设置允许时可用，从不推送到受保护的分支，并在确认对话框中写明将被替换的远程分支。正在执行的操作（如“正在推送…”）会显示在对应按钮的位置。开启自动获取（一项设置）后，所选仓库会每隔几分钟在后台获取一次；主机离线或窗口处于后台时暂停。拉取与推送的结果，以及未知主机密钥、登录被拒、推送被拒、缺少上游等失败，都会用文字说明，并提供下一步操作（先拉取、发布分支）。

## 分支、远程与标签

- **分支**：按 `/` 组织成树（`feature/login` 在 `feature` 下），标记当前分支，并显示上游、领先/落后、上游已删除、受保护分支（锁形图标）以及在其他工作树中检出的分支。可以检出（有本地更改妨碍时，面板会提议先储藏、切换、再恢复）、创建（从任意提交、分支或标签）、重命名、删除（未合并的分支仅在设置允许强制删除时可删）、合并到当前分支（可快进时快进、始终创建合并提交、仅快进或压缩合并）、将当前分支变基到该分支、设置或取消上游、与当前分支比较，以及快速切换分支（Alt+B）。
- **远程**：显示每个远程的 URL（从不显示凭据）及其分支。可以添加、重命名、修改 URL、删除、获取；将远程分支检出为本地分支；在允许时删除远程上的分支。内嵌密码或令牌的 URL 会被拒绝。
- **标签**：最新的在前，附注标签会显示其消息。可以在任意提交上创建（轻量或附注）标签、检出、推送单个或全部标签、删除本地标签、在允许时删除远程标签。

## 储藏、工作树与子模块

- **储藏**：显示消息、分支和时间。可以储藏更改（包含未跟踪文件、保留暂存区，或只储藏已暂存内容）、应用、弹出、删除，以及在允许时清空全部储藏。选中某个储藏会显示其中的文件及差异。
- **工作树**：显示路径、分支，以及它是主工作树、当前工作树、已锁定还是可清理。可以添加（基于现有分支、新分支或分离 HEAD）、打开、移除（有更改时仅在允许时可移除）、清理。
- **子模块**：显示路径、记录的提交和状态（未初始化、干净、已修改、位于其他提交、有冲突）。可以初始化并更新（也可递归）、同步 URL、打开。

## 提交图

每个提交一行，显示泳道、合并、分支、远程分支和标签，配色与 VS Code 一致（当前分支、其上游及其派生自的分支）。可显示所有分支，或只显示当前分支及其上游和基础分支。当分支与其上游分叉时，“传入”和“传出”行会显示拉取将带来的内容和推送将发送的内容。可按消息、作者、哈希、路径或内容搜索；可隐藏合并提交。鼠标停留在提交上会显示包含完整消息的卡片。Ctrl/⌘ 点击和 Shift 点击可多选提交。

对提交可以：检出；在该处创建分支或标签；拣选或还原（可同时多个，合并提交可选择主线，可选择不自动提交或记录来源）；将当前分支重置到该提交（soft、mixed、keep 或 hard——hard 仅在允许时可用，从不用于受保护分支，需输入分支名确认，并会创建安全快照）；从该提交开始交互式变基；合并或变基到其分支；比较两个提交；复制哈希。

点击分支、远程分支或标签的徽标，会打开与导航中该行相同的菜单（对应 Git Graph 的引用菜单）：检出、合并到当前分支或将当前分支变基到它、**将远程分支拉取到当前分支**、从它创建分支或标签、重命名、删除（在允许时也可删除远程上的分支或标签）、推送、设置或取消设置上游、与当前分支比较、复制名称，以及**在提交图中仅显示它**——之后可以把其他引用加入提交图或再次隐藏，也可以在列表上方的提示条中恢复显示所有分支。

**交互式变基**按从旧到新的顺序列出所选基础之后的提交，可以对每个提交选择 pick、reword（直接在原处编写新消息）、edit、squash、fixup 或 drop，并调整顺序。编辑时会实时检查计划；对已推送的提交会给出警告（并要求明确确认），对范围内的合并提交和受保护分支也会提示。因冲突或在 `edit` 处停下的变基，可以在“更改”窗格的横幅中继续。

**安全快照**在硬重置、变基、放弃更改、中止操作之前创建，可从提交图的菜单中查看（含原因和时间），一键恢复。

## 详情

- **差异**：采用 VS Code 的差异算法和布局，可并排或内联显示，标出变化的单词，约 40 种语言的语法着色，长行可换行或横向滚动，可折叠未更改区域，可显示或忽略空白变化，带概览标尺，可跳到下一处/上一处更改（F7、Shift+F7）。二进制文件、超大文件和单侧文件有各自的视图。对于更改和已暂存文件，**块**模式可以暂存、取消暂存或放弃单个块或所选的行。
- **冲突**：以 Git 自身的标签显示当前和传入两侧、共同基础，以及带冲突块的结果。可以整文件接受某一侧，也可以逐块选择当前、传入或两者并保存，或以纯文本编辑结果；没有冲突标记后即可标记为已解决。
- **提交**：主题、正文、作者和提交者及时间、父提交（可打开）、引用、签名状态，以及文件和差异。可执行的操作与提交图中相同。
- **比较**两个提交或分支：各自独有的提交数及文件。
- **文件历史**：跟随重命名，每个提交显示当时的文件路径及差异。
- **Blame**：显示每一行所属的提交、作者和时间，同一提交的连续行加底色，未提交的行单独标记；可以打开提交，或查看该提交之前的 blame。

## 设置

按主机设置，位于 Paseo 设置中的“高级 Git”下：

- **安全**：允许强制推送、允许硬重置、允许强制删除、允许删除远程上的内容（默认全部关闭），安全快照（默认开启），以及受保护的分支（`main`、`master`、`develop`、`release/*`）。
- **视图**：差异布局、自动换行、折叠未更改区域、空白字符、语法着色、代码字号、提交图范围、相对或绝对日期、自动获取及其间隔，以及放弃更改前是否询问。

## 语言

支持英文和简体中文，跟随 Paseo 的语言设置（包括“跟随系统”）；其他语言回退为英文。Git 自身的输出、提交消息、名称和路径从不翻译。
