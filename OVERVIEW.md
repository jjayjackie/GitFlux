GitFlux adds a full graphical Git client to every workspace, as a workspace tab and in the Explorer. The navigator on the left lists the workspace's repositories (nested ones, submodules and worktrees included) with the selected repository's branches, remotes, tags, stashes, worktrees and submodules. The middle shows the changes with the commit composer, and the commit graph. The right shows the diff, a commit's details, a comparison, a file's history, blame, or a conflict to resolve.

Everything goes through the system `git`, run by the plugin's daemon half on the host that owns the workspace, local or remote. The panel only draws; it opens no network service, and its state is kept per host.

Setup: Paseo 0.14.0 or later, and `git` 2.35 or later and `npm` on each host that runs the plugin. Fetch, pull and push use the git credentials of the daemon's user on that host (an SSH agent or a credential helper): git runs without a terminal, so it cannot answer a password or host-key prompt, and the plugin never asks for, stores or sends a credential. A remote URL that embeds one is refused, and URLs are shown redacted.

What it can do: stage, unstage and discard files, hunks or single lines; commit, amend, sign off, commit and push or sync; fetch, pull (merge, rebase, fast-forward only), push, publish and sync, with auto-fetch; create, check out, rename, delete, merge and rebase branches and set their upstream; add, edit and remove remotes; create, push and delete tags; stash and apply; add and remove worktrees; initialise, update and sync submodules; cherry-pick, revert, reset and interactive rebase; continue, skip or abort a merge, rebase, cherry-pick or revert; resolve conflicts side by side or block by block; search the history; follow a file's history across renames; blame. Diffs use VS Code's algorithm and layout, with syntax colours.

Safety: force push (always with lease), hard reset, deleting unmerged branches, removing worktrees with changes, clearing stashes and deleting on remotes are off until allowed in the plugin's settings for that host, and each still asks for confirmation and lists what will be lost. Protected branches (`main`, `master`, `develop`, `release/*` by default) are never force-pushed, hard-reset or deleted. Before an operation that can discard tracked changes, the plugin records them under `refs/gitflux/snapshots/` in the repository, from where they can be restored. Hooks always run.

The panel follows Paseo's language, in English or Simplified Chinese; any other language falls back to English. Keyboard shortcuts work in the desktop app and in a browser only. Settings are per host, so view preferences are shared by everyone using the plugin on that host.
